This is a [CG99](https://www.cg99.com) front-end SSR project built using [Next.js](https://nextjs.org/)

## Getting Started

First, run the development server:

```bash
pnpm dev
# or
yarn dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) to automatically optimize and load Inter, a custom Google Font.

## The main technology stack used in the project

- [Next.js](https://nextjs.org/) - Front-end SSR (server-side rendering) framework based on React.
- [TypeScript](https://www.typescriptlang.org/) - Typed JavaScript at Any Scale.
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework for rapidly building custom designs.
- [ESLint](https://eslint.org/) - Find and fix problems in your JavaScript code.
- [Arco](https://arco.design/) - A high-quality design system for enterprise-level products.
- [AutoAnimate](https://auto-animate.formkit.com/) - A tool for creating animations in Figma and exporting them to React.
- [Swiper](https://swiperjs.com/) - The most modern mobile touch slider.
- [Clsx](https://github.com/lukeed/clsx) - A tiny utility for constructing `className` strings conditionally.
- [Sass](https://sass-lang.com/) - The most mature, stable, and powerful professional grade CSS extension language in the world.
- [Framer Motion](https://www.framer.com/motion/) - A production-ready motion library for React.
